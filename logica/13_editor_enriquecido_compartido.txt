ETAPA 13: EDITOR DE TEXTO ENRIQUECIDO COMPARTIDO
Archivos: includes/rich_editor.php (limpieza HTML allowlist), assets/admin/js/rich-editor.js, assets/admin/css/rich-editor.css.
Integrado en editar_noticias.php, editar_cms.php, editar_sellos.php, editar_comunidad.php. Los campos descripcion se editan con barra WYSIWYG y siguen guardandose en seccion_item.descripcion; no se requiere SQL.
Controles: negrita, cursiva, subrayado, tachado, listas, citas, enlaces HTTPS, quitar enlace, deshacer, rehacer, color hexadecimal y bloqueo local de edicion. Bloquear NO se guarda en base de datos: solo protege temporalmente la sesion del formulario.
Servidor sanitiza etiquetas HTML permitidas y atributos. Se descartan scripts, iframes, eventos y protocolos peligrosos. Se admite color hex de seis digitos. En portada Sellos, Comunidad y Modal se conserva HTML seguro; en Noticias el resumen permanece texto plano por diseno de tarjetas.
Advertencia: el editor usa document.execCommand para compatibilidad con navegadores actuales; es API obsoleta y conviene sustituirla a futuro por libreria WYSIWYG mantenida. No se ha ejecutado lint PHP ni pruebas en cPanel. No se ha implementado en hero ni en editores sin descripcion.
Validar: git pull origin main; php -l includes/rich_editor.php; php -l editar_noticias.php; php -l editar_cms.php; php -l editar_sellos.php; php -l editar_comunidad.php; php -l componentes/patrona_cms.php; php -l componentes/modal_institucional.php. Probar crear, editar y publicar textos con listas y enlaces, confirmar sanitizacion y que no haya perdida de contenido.
